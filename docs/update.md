## v4.0.1

### 安全加固
- 密码升级为 PBKDF2-HMAC-SHA256（600,000 迭代），替代旧 SHA256
- session 增加 4 小时过期时间，自动清理过期会话
- 新增登录限流：同 IP 5 次失败锁定 60 秒
- session token 通过 HttpOnly Secure SameSite=Strict Cookie 下发，XSS 不可窃取
- 修复路径穿越漏洞（picker-timestamps / delete-file 文件名注入）
- 请求体大小限制（普通 API 1MB，上传 60MB）
- user-avatar 接口补登录校验

### 用户系统
- 每个用户新增唯一 UUID（`uid`），API 响应中返回
- users.json 结构改为 `{by_id: {uid: {...}}, by_name: {username: uid}}`
- 昵称、头像字段增加长度限制（100 / 2000 字符）

## v4.0.0

### 管理后台系统
- 新增 `admin/` 独立管理后台 SPA，访问 `/admin/` 进入
- 基于 token 的鉴权系统（sha256 加盐密码），session 管理
- 三种角色：管理员（全局管理）、教师（配置+文件）、学生（个人资料）

### 用户管理
- 管理员可 CRUD 用户：用户名（英文）、昵称（中文/日文）、头像（emoji 或图片 URL）、角色
- 所有用户可自行修改个人资料、密码
- 用户数据存储在 `admin/_store/`（不入库），HTTP 直接访问被拦截

### 可视化配置管理
- 主配置 / 化学 / 英语 / 点名四个配置文件可通过表单编辑
- 支持文本、数字、布尔、数组字段，保存后刷新页面生效

### 英语文件上传
- 管理员/教师可通过管理后台上传 xlsx/csv 文件到服务器
- 支持拖拽/点击上传，文件列表展示，可删除

### 点名系统增强
- 点名结果展示时自动加载用户头像（有则显示在名字上方）
- 查看/清空时间戳功能保留在点名弹窗中
- 顶栏新增「🔧 管理后台」入口

## v3.4.0

### 点名系统完全重做
- 模块化架构：`random.js`（算法）、`timestamp.js`（时间戳）、`animation.js`（编排）、`display.js`（展示）、`index.js`（入口）
- 三种随机方式：
  - **纯随机** — Fisher-Yates 洗牌，完全随机
  - **二分法** — 每轮洗牌后对半分，随机淘汰一半，逐步缩小直到剩一人
  - **时间加权随机法** — 多轮随机缩小子集至 ≤5 人，优先从未被点过的人中选，否则选距上次最久者
- 双层动画系统：修饰动画（全屏滚动 + 彩带）+ 过程动画（可选，展示算法步骤）
- 过程动画支持全屏 / 窗口化两种模式
- 时间戳记录存于服务端（`data/picker/`），支持开关
- CSV 第 2 列改为"个性签名"，结果展示姓名 + 签名 + 上次点名时间
- 所有配置集中管理（`config/picker/config.js`）
- 弹窗界面美化：分组布局、平滑展开、选中高亮
- 点名按钮改为 🎲，结果在左按钮在右
