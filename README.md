# SeaScribe

> 课堂听写投屏系统 — 教师大屏随机出题，学生纸笔作答，一键公布答案
>
> by **谦虚の海鸥** · v4.4.0 · [GitHub](https://github.com/qxdho/SeaScribe)

---

## 快速开始

**本地使用**（双击即可）：
```
双击 index.html → 选择学科 → 随机出题 → 公布答案
```

**一键启动**（自动打开浏览器，学科数据需 HTTP 服务）：
```
双击 start.bat
```

**部署到服务器**：
```
python server.py 9360
# 访问 http://服务器IP:9360
# 管理后台 http://服务器IP:9360/admin/  （默认 admin / admin123）
```

## 功能概览

### 主站 — 课堂投屏

| 功能 | 说明 |
|------|------|
| 随机出题 | 选学科、设数量，一键生成卡片 |
| 公布答案 | 一键展开/隐藏所有答案 |
| 布局切换 | 网格方阵 / 列表横向，任意切换 |
| 调列调字 | 列数 1-6、字号 60%-200%，无极调节 |
| 随机点名 | 纯随机 / 二分法 / 时间加权，全屏动画 + 头像 |
| 深色模式 | 🌙/☀️ 一键切换，刷新不闪烁 |

### 管理后台 — 数据管理

| 功能 | 说明 |
|------|------|
| 用户系统 | 管理员 / 教师 / 学生三种角色，PBKDF2 密码哈希 |
| 自助注册 | 学生自主注册，实时表单校验，注册后自动绑定姓名 |
| 姓名池 | 按班级管理学生名单，行内编辑、CSV 批量导入 |
| 点名记录 | 查看/清空各班级点名时间戳 |
| 个人资料 | 头像上传、班级显示、签名双向同步 |
| 文件管理 | 英语 xlsx/csv 上传，服务器端存储 |

### 学科插件

| 学科 | 数据 | 特色 |
|------|------|------|
| 化学 | H~Kr 36 元素 | 价层电子式 + 轨道式，CSV 可编辑可导入 |
| 英语 | xlsx / csv | 可调听写列/答案列，管理后台上传 |

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | HTML5 + CSS3 + Vanilla JS（零框架 SPA） |
| 后端 | Python 标准库（http.server + ThreadingMixIn 多线程） |
| 鉴权 | PBKDF2-HMAC-SHA256 · HttpOnly Cookie + Bearer Token 双通道 |
| 存储 | JSON 文件（用户·会话·名单），`admin/_store/` 不入库 |
